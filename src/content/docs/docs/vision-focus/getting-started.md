# VisionFocus をはじめよう

VisionFocus へようこそ！このガイドでは、サイトブロック・タイマー・デイリービジョンの設定方法を解説します。

## インストール

1. Chrome ウェブストアにアクセス（近日公開予定）
2. 「Chrome に追加」をクリック
3. 必要な権限を許可
4. Chrome ツールバーに VisionFocus アイコンが表示されます

## 最初のステップ

### 1. サイトをブロックする

1. ツールバーの VisionFocus アイコンをクリック
2. 「ブロック」タブを開く
3. ブロックしたい URL を入力（例：`youtube.com`）
4. 「ブロックリストに追加」をクリック

これだけで、そのサイトへのアクセスがブロックされます。

### 2. 集中タイマーをセットする

1. VisionFocus を開く
2. 「タイマー」タブを開く
3. 集中したい時間を設定
4. 「タイマー開始」をクリック

タイマーが終わると、休憩を促す通知が届きます。

### 3. デイリービジョンを作る

1. VisionFocus を開く
2. 「ビジョン」タブを開く
3. 今日の目標やビジョンステートメントを入力
4. ブロックページにビジョンが表示され、モチベーションを維持できます

## 無料 vs プレミアム

### 無料機能

- 最大 10 サイトをブロック
- 基本タイマー機能
- デイリービジョン（1件）

### プレミアム機能（$1.99/月）

- **無制限**のサイトブロック
- 高度なタイマーオプション
- 複数のビジョンステートメント
- カスタムテーマ
- 優先サポート
