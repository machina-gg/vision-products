1980年代、イタリアの大学生フランチェスコ・シリロはトマト型のキッチンタイマー（イタリア語で「ポモドーロ」）を使い、独自の時間管理術を編み出しました。それから40年以上が経った今も、世界中の知識労働者がこの方法に頼り続けています。

なぜこんなにも長く支持されているのか。その理由は脳の仕組みにあります。

## ポモドーロテクニックとは

ルールはシンプルです。

1. **25分間、1つのタスクだけに集中する**（これを「1ポモドーロ」と呼ぶ）
2. **5分間の短い休憩**を取る
3. これを4回繰り返したら、**15〜30分の長い休憩**を取る

たったこれだけです。しかしこのシンプルさの中に、脳科学的に裏付けられた複数のメカニズムが組み込まれています。

## なぜ25分なのか

25分という時間は偶然ではありません。

人間の集中力には**ウルトラディアンリズム**という90〜120分周期のサイクルがあります。このサイクルの中で、私たちは約20〜25分間は高い集中状態を保てますが、それ以降は認知パフォーマンスが落ちてきます。

25分はちょうど「集中の頂点」で意図的に切り上げる絶妙な長さなのです。

また、**エンドウェッド・プログレス効果**（終わりが見える進捗は動機を高める）の観点からも、25分という有限の時間は「もう少しで終わる」という心理的推進力を生み出します。

## 休憩の科学

ポモドーロテクニックで見落とされがちなのが、**休憩の重要性**です。

集中作業中、脳は**デフォルトモードネットワーク（DMN）**を抑制しています。このネットワークは、アイデアの統合・創造的思考・自己内省に関わる部位です。休憩中にDMNが活性化することで、脳は情報を整理し、無意識のうちに問題を解決します。

「シャワー中にいいアイデアが浮かぶ」のはDMNの働きです。ポモドーロの5分休憩は、この現象を意図的に引き起こしています。

## 実践で躓くポイントと対策

### 「25分は短すぎる」と感じる場合

乗っているときに止めるのはもったいないと感じるかもしれません。しかし、**意図的に止めることで次のポモドーロへの動機が高まります**。作業を「中途半端」な状態で終えると、脳は続きが気になり（ツァイガルニク効果）、次のセッションで自然に集中が高まります。

### 割り込みへの対処

電話・メッセージ・同僚からの声かけなど、外部割り込みは避けられません。

- **内部割り込み**（「あ、あれも調べなきゃ」）: メモに書き留めて後回しにする。今のポモドーロは継続。
- **外部割り込み**（電話など): 可能なら「5分後に折り返す」と伝え、ポモドーロを完了させる。緊急なら中断し、そのポモドーロは「無効」として数えない。

### タスクが25分より長い場合

大きなタスクは複数のポモドーロに分割します。「レポートを書く」なら「アウトライン作成（1ポモドーロ）→ 第1章執筆（2ポモドーロ）→ 校正（1ポモドーロ）」のように細分化します。

### タスクが25分より短い場合

短いタスクは複数をまとめて1ポモドーロにします。「メール返信」「ドキュメント確認」「カレンダー整理」などをまとめて1セットにしましょう。

## ポモドーロ×ウェブサイトブロックの相乗効果

ポモドーロテクニックの弱点は、**タイマーが動いていても他のタブを開けてしまう**ことです。

この問題を解決するのが、集中タイマーとウェブサイトブロックの組み合わせです。

[VisionFocus](/vision-focus/) では、タイマーが動作中に気が散るサイトへのアクセスを自動でブロックし、タイマー終了（休憩開始）とともにブロックを解除できます。ポモドーロの「25分は集中、5分は自由」というリズムをそのまま実現できます。

## 実際の1日のスケジュール例

| 時間         | 内容                               |
| ------------ | ---------------------------------- |
| 9:00〜9:25   | ポモドーロ①：メール処理・1日の計画 |
| 9:25〜9:30   | 休憩（水を飲む・軽くストレッチ）   |
| 9:30〜9:55   | ポモドーロ②：重要タスクA（前半）   |
| 9:55〜10:00  | 休憩                               |
| 10:00〜10:25 | ポモドーロ③：重要タスクA（後半）   |
| 10:25〜10:30 | 休憩                               |
| 10:30〜10:55 | ポモドーロ④：重要タスクB           |
| 10:55〜11:25 | 長い休憩（30分）← 4ポモドーロ完了  |

## まとめ

ポモドーロテクニックが40年間廃れない理由は、脳の自然なリズムに逆らわず、むしろそれを活用しているからです。

「25分集中して5分休む」というシンプルなサイクルは、集中力を持続させながら、創造性と回復力も同時に高めます。まずは今日、タイマーをセットして最初の25分を試してみましょう。
